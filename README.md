# Telegram Moon Bot

Telegram-бот для определения текущей фазы Луны и расчёта фазы на заданную дату. Бот определяет лунный возраст, процент освещённости, название фазы и дополнительно генерирует визуальное изображение Луны с соответствующей фазой.

## Про архитектуру

Проект построен на Python и использует Telegram Bot API для взаимодействия с пользователем. Расчёт фазы Луны выполняется локально на основе астрономического алгоритма без обращения к внешним сервисам.

Основная логика разделена на несколько частей:

1. **Расчёт положения Луны** — по переданной дате вычисляется положение внутри лунного цикла длительностью около 29,53 дня.
2. **Определение фазы** — полученное значение сравнивается с диапазонами, соответствующими основным фазам Луны.
3. **Расчёт освещённости** — определяется доля освещённой поверхности Луны в процентах.
4. **Генерация изображения** — на основе текстуры Луны создаётся сферическое изображение с освещением, соответствующим рассчитанной фазе.
5. **Telegram-интерфейс** — пользователь получает текстовую информацию и сгенерированное изображение непосредственно в чате.

## Основной функционал

### 1. Определение фазы на текущую дату

Бот поддерживает команду `/moon` и кнопку `🌙 Сегодня`.

В ответ пользователь получает:

* текущую дату;
* название фазы Луны;
* возраст Луны в днях;
* процент освещённости;
* визуальное изображение соответствующей фазы.

### 2. Расчёт фазы на определённую дату

Поддерживаются два формата даты:

```text
DD.MM.YYYY
YYYY-MM-DD
```

Например:

```text
15.08.2026
2026-08-15
```

Также можно использовать:

```text
/moon 15.08.2026
/moon 2026-08-15
```

Бот проверяет корректность даты и выполняет расчёт без использования внешних API.

### 3. Календарь фаз Луны

Команда:

```text
/moon month
```

или кнопка `📅 Календарь месяца` формирует календарь текущего месяца.

Для каждого дня отображаются:

* дата;
* фаза Луны;
* возраст Луны;
* процент освещённости.

Пример формата:

```text
15.08 | Прибывающая Луна |  9.2 д |  69.5%
16.08 | Прибывающая Луна | 10.2 д |  77.1%
17.08 | Полнолуние        | 11.2 д |  84.3%
```

## Генерация изображения Луны

Для визуализации используется текстура поверхности Луны и библиотека Pillow.

Изображение формируется в несколько этапов:

1. Текстура Луны преобразуется в сферическую проекцию.
2. Для каждого пикселя рассчитывается положение точки на поверхности сферы.
3. Определяется направление освещения в зависимости от фазы.
4. Рассчитывается интенсивность освещения поверхности.
5. Освещённая текстура объединяется с маской сферической формы.
6. Добавляются размытие, свечение, яркость и контраст.

Для математических операций над изображением используется NumPy.

В результате бот отправляет пользователю отдельное изображение Луны, соответствующее рассчитанной фазе.

## Основные технологии

* **Python 3**
* **python-telegram-bot** — взаимодействие с Telegram Bot API
* **NumPy** — математические операции и обработка массивов изображения
* **Pillow** — обработка текстуры и генерация изображения
* **datetime** — работа с датами
* **calendar** — формирование календаря месяца
* **math** — математические и астрономические расчёты
* **re** — обработка и проверка форматов дат

## Требования к окружению

Для запуска проекта необходим:

* Python 3.10+
* Telegram Bot Token

Токен бота не должен храниться непосредственно в исходном коде или публиковаться в GitHub.

Рекомендуемый вариант — использовать переменную окружения:

```text
BOT_TOKEN=ваш_токен
```

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/your-username/telegram-moon-bot.git
cd telegram-moon-bot
```

2. Создайте виртуальное окружение:

```bash
python -m venv venv
```

3. Активируйте виртуальное окружение.

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

5. Добавьте токен Telegram-бота в переменные окружения.

6. Убедитесь, что файл текстуры Луны `8k_moon.jpg` находится в корневой директории проекта.

7. Запустите бота:

```bash
python main.py
```

## Команды

| Команда            | Назначение                     |
| ------------------ | ------------------------------ |
| `/start`           | Запуск бота и отображение меню |
| `/moon`            | Фаза Луны на текущую дату      |
| `/moon DD.MM.YYYY` | Фаза Луны на указанную дату    |
| `/moon YYYY-MM-DD` | Фаза Луны на указанную дату    |
| `/moon month`      | Календарь фаз текущего месяца  |

Также даты можно отправлять обычным текстовым сообщением без использования команд.

## Обработка ошибок

Бот проверяет корректность введённой даты и обрабатывает некорректные форматы.

Поддерживаются:

* проверка количества дней в месяце;
* проверка високосных годов;
* проверка формата даты;
* обработка неизвестных команд и аргументов.

## Безопасность

Токены Telegram-бота не должны попадать в исходный код и публичный репозиторий.

Для локального запуска рекомендуется использовать `.env` или переменные окружения, а файл `.env` добавить в `.gitignore`.

Пример `.gitignore`:

```text
.env
venv/
__pycache__/
*.pyc
```
